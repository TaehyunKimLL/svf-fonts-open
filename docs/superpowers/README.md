# Design documents and implementation plans

`specs/` holds the design of each feature and `plans/` its implementation plan, named by date. They are the working
record of the original development repository, kept as written: they still name faces, tools, card numbers, branches,
commits and local paths of that repository which this public repository leaves out (faces without a stated open
licence, game-specific bake scripts, research runs). The current state is in the code, `docs/tools.md`,
`docs/recipes.md` and `docs/STATUS.md`.

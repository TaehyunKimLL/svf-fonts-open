**Goal:** Add JSET block version 2 (bit-packed set cells, per-set rows with presence and alias bitmaps, compat as set
bytes) beside version 1 in SVF v3, as an **exception-only** format for memory-constrained targets. Version 1 stays the
standard: every writer defaults to `--jset-version 1`, and `2` or `auto` (`auto` = v2 when the v1 block is >= 1024 B
larger) are explicit choices for a build or pack. C readers are compiled by define (`SVF_JSET_V1`, `SVF_JSET_V2`; AVR
defaults to v1 only, every other target to both). `svf/` stays v1; the pixel-identity proof per version runs on v2
copies generated under `c/build/jset2/`. Gates: the v1-only build within +20 B of BASE; the default builds reported;
Pico rows from the (v1) shipped bench face not slower than BASE.

**Architecture:** `tools/jamoset.py` is the reference: `pack` writes v2 from resolved `Tables` and returns the
old-to-new piece map, `pack_v1` writes v1, `pack_jset(t, version)` chooses, and `unpack` validates either version and
returns the same `Tables` shape as before, so readers above it (`svfline`, `maker/detect.py`, `svf_synth`, `bdfface`,
scummvm-korean's `facecoverage.py`) do not change. The C library has both readers in `c/src/svf_jamo.c`, each behind
its public switch, plus a popcount-table switch and a trusted-faces switch (Task 3, done).

**Tech Stack:** C99 (`-std=c99 -Wall -Wextra -Werror`), make, POSIX sh, Python 3 unittest, libFuzzer (clang
`~/opt/llvm-23.1.3/bin/clang`); the cross toolchains and emulators of `c/cross/install-toolchains.sh` and
`c/bench/install-emulators.sh` (arm-none-eabi-gcc 15.2.1, avr-gcc 16.1.0, DJGPP gcc 12.2.0, rp2040js 1.4.0, simavr
1.8, DOSBox-X, emcc 6.0.13, node `~/opt/node-v24.13.0-linux-x64/bin/node`).

## Global Constraints

- **Format, verbatim from the spec.** Block magic `"JSET"`, u16 version **2**, then LC, TC, NI, NM, NF, advance (u8
  each), u16 NA, u16 reserved 0. After those: `leadClass[19]` at 16, `tailClass[28]` at 35, the set table at 63
  (`S = ceil(LC*21*TC*W / 8)`), the initial, medial and final set rows, `NA*2` bytes of alias table, then
  `compat[51]`.
  - `width(n) = 0` for n = 1, else `ceil(log2 n)`. W = WI + WM + WF, with the initial set in the low bits, then the
    medial, then the final. Cell `c` holds bits `c*W .. c*W+W-1`, LSB-first.
  - Rows: NA = 0 gives `u16 base | presence PB`, so RI = RM = 5 and RF = 6. NA > 0 gives
    `u16 base | u16 abase | presence PB | alias PB`, so RI = RM = 10 and RF = 12. PB is 3, 3, 4. Final slot of tail t
    is bit t-1.
  - The piece of a drawn slot: if its alias bit is set, `alias[abase + popcount(alias & below(j))]`; otherwise
    `base + popcount((presence & ~alias) & below(j))`.
  - Compat byte: 0xFF means no piece. Otherwise bits 0-4 are a set, bits 5-6 are 0, and bit 7 switches a lead-capable
    consonant to the final table.
  - `size = 63 + S + NI*RI + NM*RM + NF*RF + 2*NA + 51`.
  - `SVF__JSET_MAX` = **9246**; `SVF__JSET_LOAD_MAX` = 12,321 when `SVF_JSET_V1` is compiled, else 9,246.
  - The limits are unchanged: LC, TC <= 12; NI <= 32; NM <= 24; NF <= 16; NA <= NI*19 + NM*21 + NF*27.
  - Version 1 is today's block, unchanged, and the standard format.
- **Pinned sizes.** `jset_size(8, 8, 32, 24, 12) == 2818`; `jset_size(2, 2, 8, 4, 4) == 272`;
  `jset_size(1, 2, 6, 2, 1) == 181`; `jset_size(12, 12, 32, 24, 16, 1544) == 9246`;
  `jset_size(12, 12, 32, 24, 16) == 5782`. The 95 shipped jamo faces in `svf/` total 652,431 B of JSET, all v1, and
  stay so. Their copies written with `--jset-version auto` (`c/build/jset2/svf`): 37 faces v1 = 36,797 B, 58 faces v2
  = 300,898 B, total 337,695 B (measured in Tasks 5 and 6).

  `--jset-version 1`; `2` and `auto` are explicit. The one exception is `tools/svf_synth.py`, a test tool, whose
  `--jset-version` keeps its default 2 (its docstring says so).

NanumGothic Bold faces (NGOTB*.SVF, NGO*X?.SVF)
===============================================

Bitmap faces rasterised from NanumGothic Bold by mkfont.py: 2
bpp anti-aliased from the Google Fonts build, and the 1 bpp NGOTB17 (and its
supplements) from NHN's hinted original with FreeType's
monochrome hinting (--mono-hint). Each is a Modified Version (a rasterised
subset) of the font. Copyright (c) 2010, NHN Corporation
(http://www.nhncorp.com). SIL Open Font License 1.1: OFLNANUM.TXT.

Names: <font><px>[variant].SVF. <px> is the size the face was drawn at; a
letter after it tells apart faces of the same font and size (another cell,
bit depth or character set). A name ending in X<n> is a supplement: the few
characters a base face lacks, drawn to follow it in a chain. The file names
are abbreviations, not a Reserved Font Name, and the faces carry no font name
inside: they are Modified Versions under the SIL OFL 1.1 that do not use the
Reserved Font Names of the original. How each face is made: tools/build/faces.tsv
and docs/recipes/svf-faces.md.
